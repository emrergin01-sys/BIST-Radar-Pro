# BIST Radar Pro

Mobil uyumlu BIST finansal izleme paneli — **ilk demo sürüm**.

## Şu anda çalışan özellikler
- Statik, responsive kontrol paneli
- ORGE, TUPRS, INDES, MPARK, ISDMR araştırma izleme listesi
- Hisse araması ve alfabetik sıralama
- Canlı veri olmadığını belirten açık demo etiketi

## Netlify üzerinde ücretsiz yayınlama
1. Netlify hesabında **Add new project → Import an existing project** yolunu izle.
2. GitHub hesabını bağla ve `emrergin01-sys/BIST-Radar-Pro` deposunu seç.
3. Build command: **boş**; Publish directory: **.** (repo kökü).
4. **Deploy** ile yayınla. Netlify sitenin adresini oluşturacaktır.

Bu depo herkese açıktır. **Fintables abonelik verilerini, kişisel finansal verileri, API anahtarlarını veya erişim bilgilerini yüklemeyin.**

## Sonraki teknik aşamalar
- Lisansı doğrulanmış piyasa verisi kaynağı
- Sunucu tarafında zamanlanmış güncellemeler (borsa saatleri dahil)
- Temel analiz ölçütlerinin sektöre göre doğrulanması
- Sinyal geçmişi, risk kontrolleri ve günlük raporlar
- WhatsApp gönderimi için uygun resmi entegrasyonun değerlendirilmesi

## Uyarı
Panel şu anda **gerçek zamanlı değildir**. İçerik yatırım danışmanlığı veya al/sat tavsiyesi değildir.
